## Progetti in evidenza

Una selezione di progetti sviluppati durante il percorso ITS Academy, scelti per rappresentare differenti aspetti dello sviluppo software.

### 01 - Gestione Iscrizioni API

**Java · Spring Boot · PostgreSQL · JPA · Flyway · Docker**

API REST per la gestione di studenti, docenti, corsi e iscrizioni.

Il progetto approfondisce la modellazione del dominio, la separazione delle responsabilità, la persistenza relazionale e l'implementazione di regole applicative, con particolare attenzione all'organizzazione architetturale del backend.

**Aspetti principali:** REST API, architettura a livelli, DTO, relazioni tra entità, validazione e testing.

[Esplora il progetto](https://github.com/arlonarl/gestione-iscrizioni-api)

### 02 - Editor di Topologie di Rete

**Angular · TypeScript · Express · MongoDB · SVG**

Applicazione full-stack per la creazione e la gestione interattiva di topologie di rete.

Consente di posizionare dispositivi, definire collegamenti, modificare configurazioni e salvare le topologie, attraverso un'interfaccia grafica integrata con un backend dedicato.

**Aspetti principali:** Angular Signals, gestione dello stato, interazioni grafiche, API REST, validazione e persistenza NoSQL.

[Esplora il progetto](https://github.com/arlonarl/editor-topologie-rete)

### 03 - IT Operations Center

**Python · Django · SQLite · Requests · Bootstrap · Chart.js**

Applicazione per la gestione operativa di risorse e servizi IT, con inventario degli asset, gestione degli incidenti, monitoraggio HTTP/HTTPS e dashboard interattiva.

Il progetto integra controlli sullo stato dei servizi, registrazione degli eventi e apertura automatica degli incidenti in presenza di anomalie. Comprende inoltre una CLI Python per la gestione di asset e incidenti tramite terminale, con persistenza indipendente dall'applicazione web.

**Aspetti principali:** Django ORM, gestione degli asset e degli incidenti, monitoraggio HTTP, automazioni, autenticazione, persistenza e testing.

[Esplora il progetto](https://github.com/arlonarl/it-operations-center)

### 04 - Database Manutenzione Aziendale

**MySQL · SQL · MongoDB · Node.js · Express**

Progetto dedicato alla modellazione e gestione dei dati per uno scenario di manutenzione aziendale.

Comprende la progettazione di un database relazionale, interrogazioni SQL e un'estensione NoSQL che reinterpreta parte del dominio in MongoDB, accompagnata da un'interfaccia CRUD sviluppata con Node.js.

**Aspetti principali:** modellazione ER, integrità referenziale, query SQL, progettazione documentale e operazioni CRUD.

[Esplora il progetto](https://github.com/arlonarl/database-manutenzione-aziendale)
